# AyuGram Sync 0.1 Preview

```text
Прочитай README AyuGram Sync, распакуй ZIP и запусти проверку на тестовых данных.
Помоги запустить архив на одном компьютере или подключить второй через мой SSH или HTTPS. Мою базу и токен оставь на моих устройствах.
```

AyuGram Sync переносит сохранённые правки и удаления текста из копии базы AyuGram Desktop в отдельный архив. С него можно скачать записи на другой компьютер. Достаточно Python 3.9 или новее. Дополнительные пакеты не нужны.

В этом превью импорт и скачивание запускаются вручную. За один импорт выбирается один личный чат. Результат открывается через команду `history`. Фонового сбора, Android, медиа и встраивания в ленту AyuGram пока нет.

## Попробовать на примере

Распакуй ZIP и открой терминал в папке с `sync.py`. Проверь версию через `python3 --version` на macOS или Linux и `py -3 --version` на Windows. Если Python ещё нет, установи его с [python.org](https://www.python.org/downloads/). Если на Windows работает команда `python`, используй её вместо `py -3`.

На macOS или Linux:

```sh
python3 -B test_roundtrip.py -v
```

В PowerShell на Windows:

```powershell
py -3 -B test_roundtrip.py -v
```

Проверка создаст временную базу с вымышленной правкой и удалением, передаст их двум архивам и перезапустит сервер. В конце будет `OK`. Для знакомства с командами запусти `python3 sync.py --help`.

## Запустить свой архив

Оба компьютера используют один экземпляр архива. Для первого импорта хватит одного компьютера и двух окон терминала. Сервер по умолчанию доступен только по адресу `http://127.0.0.1:8765` на этом компьютере.

Создай токен один раз в закрытой папке и запусти сервер:

```sh
umask 077
python3 -c "import secrets; open('owner.token', 'x').write(secrets.token_urlsafe(32))"
export AYU_SYNC_TOKEN="$(cat owner.token)"
python3 -B sync.py serve --db server.sqlite3
```

В PowerShell те же действия:

```powershell
py -3 -c "import secrets; open('owner.token', 'x').write(secrets.token_urlsafe(32))"
$env:AYU_SYNC_TOKEN = (Get-Content .\owner.token -Raw).Trim()
py -3 -B sync.py serve --db server.sqlite3
```

Скопируй значение токена в переменную `AYU_SYNC_TOKEN` во втором терминале. На другом компьютере используй свой SSH туннель к серверу:

```sh
ssh -N -L 8765:127.0.0.1:8765 user@host
```

Замени `user@host` на свой SSH адрес. Оставь туннель открытым, а команды архива выполняй через локальный `http://127.0.0.1:8765`. Если у тебя уже настроен HTTPS прокси перед архивом, укажи его URL в `--url`. Экземпляр рассчитан на одного владельца. Токен открывает весь архив, а тексты хранятся в SQLite в читаемом виде. Храни токен, архив и резервные копии в своих закрытых папках.

## Выбрать чат и перенести записи

1. Полностью выйди из AyuGram Desktop. Найди `tdata/ayudata.db` в папке профиля. Точный путь показывает строка `Working dir:` в журнале запуска. Стандартный профиль часто лежит в `~/Library/Application Support/AyuGram Desktop/` на macOS или в `%APPDATA%\AyuGram Desktop\` на Windows. У портативных сборок путь может отличаться.
2. Если рядом с исходной базой остались файлы `ayudata.db-wal`, `ayudata.db-shm` или `ayudata.db-journal`, для импорта понадобится согласованный отдельный SQLite бекап. Если таких файлов нет, скопируй `ayudata.db` в рабочую папку и назови копию `ayudata-copy.db`. Исходный файл оставь в профиле.
3. Посмотри, по каким личным чатам в копии уже есть сохранённые записи:

```sh
python3 -B sync.py list-chats --db ./ayudata-copy.db
```

`account_id` означает твой аккаунт, `dialog_id` означает собеседника. Сверь номера с ID в клиенте AyuGram. Вместо `101` и `202` ниже подставь нужную пару. В `--source` укажи постоянную метку устройства, например `mac-home`. Используй ту же метку при повторном импорте копии с этого устройства.

```sh
python3 -B sync.py import-desktop --db ./ayudata-copy.db --url http://127.0.0.1:8765 --source mac-home --account 101 --dialog 202
```

Затем скачай архив локально или на другом компьютере. Если запускаешь из PowerShell, замени `python3` на `py -3`.

```sh
python3 -B sync.py pull --db client.sqlite3 --url http://127.0.0.1:8765
python3 -B sync.py history --db client.sqlite3 --account 101 --dialog 202 --text
```

Архив показывает текст до правки и сохранённую версию удалённого сообщения. Записи с разных устройств сохраняются с указанием источника. Если нужно время из исходной базы и другие поля, убери `--text`: результат будет в JSON Lines. Если `list-chats` вывел только шапку, в копии нет сохранённых записей для личных чатов.

После прерывания повтори импорт с тем же файлом и `--source`. Уже загруженные записи этой копии не дублируются. Следующий `pull` в тот же файл скачает только новые записи. Для бекапа останови сервер и сохрани `server.sqlite3`. При откате сервера к старому бекапу скачай архив заново в новый клиентский файл.

## Связанный фикс AyuGram Desktop

[PR #530](https://github.com/AyuGram/AyuGramDesktop/pull/530) возвращает уже сохранённый удалённый текст в обычную ленту личного чата после перезапуска. Это отдельная доработка Desktop. Её проверяли на macOS arm64. Статус выпуска смотрите в PR.

При тестировании разных версий AyuGram выделяй каждой свой каталог профиля. На тестовой копии запуск 6.3.10 поверх профиля 7.2.9 перезаписал список учёток. AyuGram Sync работает с копией `ayudata.db` и хранит свой архив отдельно от профиля клиента.
