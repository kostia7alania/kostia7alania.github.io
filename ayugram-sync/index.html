AyuGram Sync

Перенеси сохранённые правки и удаления из копии AyuGram Desktop в свой архив. Его можно открыть и на втором компьютере.

Скачать ZIP Открыть инструкцию

Попробовать на примере

Распакуй ZIP, открой терминал в этой папке и запусти проверку. Нужен Python 3.9 или новее.

macOS / Linux
python3 -B test_roundtrip.py -v

Windows PowerShell
py -3 -B test_roundtrip.py -v

Пример создаст тестовую правку и удаление, передаст их двум архивам и выведет OK.

Что умеет превью

Можно посмотреть, по каким личным чатам есть записи, вручную импортировать один чат и открыть его сохранённый текст. Архив запускается на своём компьютере. Фоновый сбор, Android и вложения пока не поддерживаются.

Фикс ленты Desktop

Отдельный патч возвращает сохранённый удалённый текст в обычную ленту личного чата. Патч проверен на macOS arm64. Статус выпуска указан в PR.
