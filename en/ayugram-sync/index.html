AyuGram Sync

Move saved edits and deletions from an AyuGram Desktop backup to your own archive. You can open it on a second computer.

Download ZIP Open setup guide (Russian)

Try sample data

Unzip the download, open a terminal in its folder and run the check. You need Python 3.9 or newer.

macOS / Linux
python3 -B test_roundtrip.py -v

Windows PowerShell
py -3 -B test_roundtrip.py -v

The demo generates a sample edit and deletion, sends both to two archives and prints OK.

What the preview supports

List private chats with saved records, import one chat at a time and read its saved text. The archive runs on your own computer. Background capture, Android and attachments are outside this preview.

Desktop chat history fix

A separate patch restores saved deleted text to the regular private chat history. It was tested on macOS arm64. See the PR for release status.
