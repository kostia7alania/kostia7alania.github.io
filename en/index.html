About me

Over eight years in commercial frontend engineering.

In recent projects I’ve worked with Vue and TypeScript. I trace user journeys and API contracts, build components, test key flows and take changes through to release.

In my own projects I build static websites, integrations and tools that use local models. I care about interfaces that make the first step clear and code that’s straightforward to extend.
